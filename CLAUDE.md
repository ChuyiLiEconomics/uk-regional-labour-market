# Project research rules

This file contains project-specific instructions. The generic scaffold skill's external personal template was not available; this file was authored for this project.

- Use official ONS data through Nomis; record exact queries, retrieval times and immutable raw snapshots.
- Validate geography names and codes rather than trusting numeric IDs alone.
- Keep missing or suppressed observations distinct from zero. Preserve source status flags.
- This is descriptive analysis of overlapping annual survey estimates. Do not claim causal effects, independent quarterly observations, vacancy demand or hiring probabilities.
- Never include private CVs, application records, credentials, licensed financial data or employer correspondence in this repository.
- The author is an Economics PhD candidate. Do not claim an awarded degree or unconfirmed skills or achievements.
- Use temporary in-memory databases for automated tests. The career-management application's database is outside this project.
- Describe AI assistance honestly. The author should review, run and understand the implementation before presenting it as a work sample.
- Public release requires the user's explicit approval. No repository has been created or uploaded by preparing these local files.
